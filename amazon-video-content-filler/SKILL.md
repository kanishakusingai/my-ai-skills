# Amazon product video upload fields

Prepare values the seller can copy into Seller Central → Upload video. The seller's November 2026 screenshot is the reference for the field order and options below. Follow the current form when its fields, labels, options or guidance differ.

## Identify the product and the footage

Read the conversation and inspect the supplied video, screenshots and product details before asking for information.

- Use the listing and, for OMSHRIM, the sibling seller context and product registry when available to identify the intended ASIN/SKU, verified brand, model and variations. Verify the current product identity. A filename or third-party logo can be a clue to reused footage. If a visible model, logo or accessory conflicts with the listing, identify the exact difference and mark the affected association for confirmation.
- Use the footage or the seller's account of its scenes to establish what happens in the clip. The listing may describe features the clip never shows. Use the audio and meaningful on-screen text to identify the language. OMSHRIM and English were selected in the reference screenshot. Each needs support from the current product or clip.
- If you cannot inspect the clip, use the evidence already supplied. Ask for a short description of the scenes and language only where needed. Draft every supported field and bundle consequential unknowns into one short question. For example, if the ASIN and scene are known, ask only which language the speaker uses.

## Choose the video type by what the shopper sees

Select one primary label available in the form. For a clip that covers several activities, choose the one that best describes its main purpose. For example, a brief box opening followed by a demonstration of how to operate the product fits **How to** if the demonstration teaches the steps. Recommend multiple types only when the current form supports them and the footage warrants them.

| Main purpose of the footage | Reference form label |
| --- | --- |
| Introduce the product and show its features or give a general demonstration | Product overview |
| Open the package and show what comes inside | Unboxing |
| Teach the shopper how to use the product | How to |
| Show assembly, installation or first-time setup | Setup |
| Diagnose or resolve a specific problem | Troubleshooting |
| Tell the brand's story | Brand story |
| Show content that falls outside the available categories | Other |

## Prepare the copy-ready values

Return a compact field/value table in the current form's order. Use these seven rows for the reference form. Keep instructions and questions outside copyable values. Where a value is unresolved, mark that row **Needs confirmation** and identify the missing detail.

| Field | How to choose the value |
| --- | --- |
| Title | Recommend one title naming the product and the main action shown. Use plain customer language and match the video's language unless the seller requests another. Use verified features and omit prices, discounts, ranking claims, guarantees and keyword stuffing. Aim for fewer than 60 characters, the reference form's recommendation. Count the exact final title including spaces and punctuation with a character-counting tool when available. Put the count outside the copyable title. |
| Video type | Enter the selected label from the current form. |
| Brand association | Match the verified product brand to an available option. If the brand is missing, flag it for the seller and leave the selection unresolved. |
| Language of video | Match the speech and meaningful on-screen text to an available option. For a silent or mixed-language clip with no clear match, consult the current form guidance or ask the seller. |
| Thumbnail | Choose a sharp frame that clearly shows the actual product or its main demonstrated use. Give a timestamp only after inspecting the video. With a screenshot alone, assess the visible thumbnail and describe the desired frame. Create a separate thumbnail file only on request. |
| Target ASIN/SKU | Give the verified identifier when known. Resolve a material footage/listing mismatch before applying the association. |
| Include product variations | Enable only when the seller intends the association and the clip accurately represents the selected variants. Otherwise leave the switch off. Flag visible differences such as colour, capacity or included accessories that could mislead a shopper. |

Add a description or tags only when requested or present in the current form. Include a script only when requested or required by a current form field.

## Fill or submit when requested

For a request to fill the form, check which available tools support the current video workflow and fill the supported fields within the requested scope. Follow any required tool approvals. If the form is inaccessible or only some fields can be filled, deliver the remaining copy-ready values and say exactly what still needs filling.

Drafting metadata or creating this skill grants no authority to upload or submit a video. Treat video generation, upload and submission as separate actions. Submit only when the seller requests submission and the required approvals succeed. Report the actual result and claim success only when the tool or form confirms it.

## Write a short voiceover when requested

Use verified actions visible in the footage or otherwise established for the product. Match the requested duration. For a ten-second English voiceover, about 20–25 spoken words is a starting estimate. Adjust for pace and pauses, and label the timing as estimated unless a recording was timed. Avoid invented instant results, runtime, safety claims or unsupported functions.
